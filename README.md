# Práctico 1 – Maquetando con Flexbox (versión 2)

## Abrir el proyecto
Descomprimí la carpeta y abrí `index.html` con doble clic en tu navegador.

## Archivos
- `index.html`: estructura y contenido.
- `style.css`: estilos y maquetación con Flexbox.
- `app.js`: interacción del menú.

## Dónde se utiliza Flexbox
- `.nav`: alinea el logotipo, el menú y el botón.
- `.hero-layout`: organiza la portada en dos columnas y centra verticalmente.
- `.features`: distribuye tarjetas y permite que pasen a otra fila con `flex-wrap`.
- `.project-grid`: arma la galería con tarjetas flexibles.
- `.contact-row` y `.footer-row`: alinean y distribuyen sus elementos.

## Publicar en GitHub Pages
1. Subí los tres archivos a la raíz de un repositorio.
2. Abrí Settings → Pages.
3. En Build and deployment elegí Deploy from a branch.
4. Seleccioná `main` y `/ (root)`, y guardá.
5. Abrí el enlace que GitHub Pages genere.

Las imágenes y la tipografía externas requieren conexión a Internet.
